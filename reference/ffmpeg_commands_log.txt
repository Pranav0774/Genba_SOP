FFMPEG COMMANDS LOG — Genba Video to SOP Generator
======================================================

1. AUDIO EXTRACTION (video -> audio, used for every video before transcription)
------------------------------------------------------------------------------
ffmpeg -y -i <VIDEO_PATH> -ar 16000 -ac 1 <AUDIO_OUTPUT_PATH>

Example (eng_03):
ffmpeg -y -i D:\genba-sop\videos\english\eng_03.mp4 -ar 16000 -ac 1 D:\genba-sop\videos\english\eng_03_audio.wav


2. NOISE MIXING (clean audio + factory noise at controlled dB levels)
------------------------------------------------------------------------------
Used to create the 20dB / 10dB / 5dB noisy test versions of eng_03's audio.

20 dB (light noise):
ffmpeg -i D:\genba-sop\videos\english\eng_03_audio.wav -i D:\genba-sop\noise_samples\factory_noise.flac -filter_complex "[1:a]volume=-20dB[noise];[0:a][noise]amix=inputs=2:duration=first" D:\genba-sop\videos\noise_mixed\eng_03_20db.wav

10 dB (moderate noise):
ffmpeg -i D:\genba-sop\videos\english\eng_03_audio.wav -i D:\genba-sop\noise_samples\factory_noise.flac -filter_complex "[1:a]volume=-10dB[noise];[0:a][noise]amix=inputs=2:duration=first" D:\genba-sop\videos\noise_mixed\eng_03_10db.wav

5 dB (heavy noise):
ffmpeg -i D:\genba-sop\videos\english\eng_03_audio.wav -i D:\genba-sop\noise_samples\factory_noise.flac -filter_complex "[1:a]volume=-5dB[noise];[0:a][noise]amix=inputs=2:duration=first" D:\genba-sop\videos\noise_mixed\eng_03_5db.wav


3. AUDIO DENOISING (attempted on jap_03 to test if noise removal improves accuracy)
------------------------------------------------------------------------------
ffmpeg -i D:\genba-sop\videos\japanese\jap_03_audio.wav -af "highpass=f=200, lowpass=f=3000, afftdn=nf=-25" D:\genba-sop\videos\japanese\jap_03_audio_denoised.wav

Result: Denoising did NOT improve accuracy (CER went from 53.66% to 57.26%),
suggesting noise and speech frequencies overlap significantly in this recording.


4. VERIFY FFMPEG INSTALL
------------------------------------------------------------------------------
ffmpeg -version
